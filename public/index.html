What is this tool?

            
WalletHunter is a demonstrative dashboard to generate random wallet batches and scan Ethereum and BNB Smart Chain for addresses with a balance. It is meant for learning and experimentation — not financial advice.

            
Generate → Scan → Findings

          

          

            
Quick start

            
    
              
  1. Open Config and add your email settings (optional).
    2. 
              
  2. In Generation, start ETH and/or BNB generation.
    3. 
              
  3. In Scan ETH or Scan BNB, start the scan when batches are queued.
    4. 
              
  4. Check Findings for any wallet with balance.
    5. 
              
  5. Use Retry if batches land in the failed folder.
    6. 
            

          

        


        

          

            
Header counters

            
Live stats shown at the top of the dashboard.

            

              
ETH queue
Batches waiting in the ETH scan queue (wallets_scan_eth/). Each file holds 1,100 wallets.

              
BNB queue
Same for BNB Smart Chain (wallets_scan_bnb/).

              
Scanned
Total batch files already processed and stored in wallets_scanned/ (ETH + BNB combined).

              
Findings
Wallets with balance > 0 found so far.

              
Style
Switch between Modern and Classic below the author name in the footer.

              
Connection
Live link to the server. Green = connected; logs and status update in real time.

            

          

        


        

          

            
Generation tab

            
Creates random wallet batch files on disk, ready for scanning.

            

              
Start / Stop
Run or stop wallet generation for ETH or BNB independently.

              
Wallets generated
How many batch files exist per network (files × 1,100 = total wallets).

              
Console
Live output from the generator. Use Clear to empty the view.

            

          

        


        

          

            
Scan ETH / Scan BNB tabs

            
Read queued batches and check on-chain balances via RPC.

            

              
Queue
Batches still waiting to be scanned on that network.

              
Start / Stop
Begin or stop the scan job for that chain.

              
File scanned now
Which batch file is being processed right now.

              
Files left to scan
How many batches remain after the current one.

              
Failed folder
If a scan fails, the batch moves to wallets_failed_eth/ or wallets_failed_bnb/.

              
Retry
Re-process failed batches from that folder. On success they go to wallets_scanned/.

              
RPC in use
Which RPC endpoint is active while scanning (shown above the console).

              
Console
Live scan logs for that network.

            

          

        


        

          

            
Findings tab

            
Table of funded wallets detected during scanning.

            

              
Date
When the wallet was found.

              
Network
ETH or BNB chain.

              
Address / Balance
Public address and detected balance.

              
File
Source batch file.

              
Private key
Click a cell to copy it to the clipboard.

              
Refresh
Reload the table from disk.

            

          

        


        

          

            
Config

            
Footer button with two tabs: Email and RPC.

            

              
Email
Sender email and recipient for balance alerts.

              
RPC
Custom Ethereum and BNB endpoint lists (one URL per line). Saved to rpc-config.json.

              
Defaults
Public RPC lists from the repo are used until you save your own.

              
GitHub / Star / Donate
Links in the footer.

            

          

        

      


      

        
      

    

  


  

    

      

        
Config

        
      


      

        
        
      


      

        

          
Set up your sender email and recipient address to receive an alert when a wallet with a balance is found.

          
          
          
          
        


        

          
One RPC URL per line. Saved to rpc-config.json on your machine (ignored by Git). Public users should add their own keys here — do not use someone else's private endpoints.
